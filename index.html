算法说明

本页把附件 MATLAB 程序里的思路做成可交互仿真：只对傍轴光线做 ABCD 矩阵迭代，而不是求解波动方程。注释里写得很清楚——追迹结果依赖于初始 (r, θ)，因为这是几何光学，不是本征模求解。

对单根光线进行追迹，而不是计算多根光线。目前仍存在问题：追迹的结果和光线的初始参数有关。

原脚本把一次往返展开到 z ∈ [0, 2L]：腔内透镜在去程、回程各作用一次，两端反射镜分别出现在 s = L 与 s = 2L。默认参数对应：

  • 腔长 L = 40 mm，两端凹面镜 R = 80 mm（空腔 g = 0.5）
  • 薄凸透镜 f = 70 mm，放在距左镜 35 mm 处（去程 35 mm、回程 45 mm 各折射一次）
  • 初始平行偏轴光线 r₀ = 60 μm，θ₀ = π/720

ABCD 光线矩阵

光线矢量 (r, r′)，r′ = dr/ds 为沿传播方向的斜率。遇到元件时左乘对应矩阵：

自由空间 d：  [ 1 , d ; 0 , 1 ]    薄透镜 f：  [ 1 , 0 ; −1/f , 1 ]    球面镜 R：  [ 1 , 0 ; −2/R , 1 ]

符号约定与原程序一致：R > 0、f > 0 表示对入射光线会聚（凹面镜 / 正透镜）。平面镜取 C = 0。

一次完整往返的合成矩阵 Mrt 满足

m = (A + D) / 2，  稳定 ⇔ |m| < 1

空腔（无透镜）还可写成 gi = 1 − L/Ri，稳定区为 0 < g₁g₂ < 1。插入透镜后应以往返 m 为准，右侧 g₁–g₂ 图仍画出空腔工作点，便于对照腔型。

腔内透镜与腔型

改 R₁、R₂、L 即改变谐振腔的几何形状：平行平面、共焦（R = L）、共心（R = L/2）、半球、近稳长腔等。透镜按傍轴薄透镜处理，外形按等凸/等凹球面绘制，折射率取 n = 1.5，故曲率半径 Rsurf = f。各透镜默认共用同一外径（与第一片对齐）；仅当边厚低于 0.35 mm 时才自动缩小那一片的外径，避免透镜画成负边厚。

展开图的横轴是光程 s，一个往返长度为 2L，各圈轨迹叠在同一区间上，对应 MATLAB 中 trace(:,cycle) 对 z 的叠加画法。物理视图则把回程折叠回 [0, L]，更接近真实腔体。

高斯本征模（可选）

稳定腔存在自洽 q 参数：q = (Aq + B)/(Cq + D)。取 Im(q) > 0 的根，再沿腔逐段变换，得到 1/e² 半径

w(z) = √[ λ / (π Im(−1/q(z))) ]，  默认 λ = 632.8 nm

它给出的是衍射极限的腔模包络，与上面那根几何光线不是同一回事。几何光线在稳定腔内会绕光轴振荡，包络由初始条件决定；高斯模则是往返相位自洽的基模。
